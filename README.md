# 合成大一中

福州老九所校徽主题 2048。单文件静态网页，图片、样式、游戏逻辑和求解器均已内置，无需安装依赖。

## 操作

- 电脑：方向键或 WASD。
- 手机：在棋盘内滑动，或点击方向按钮。
- 支持撤回一步、当前浏览器自动存档、最高分、九校图鉴、音效开关和数字视图。
- 棋盘下方的“智能助攻”支持提示方向、执行一步和自动求解，并提供三档播放速度。
- 点击暂停、按 Esc、手动移动、打开弹窗或切到后台，都会停止自动求解；合成 2048 时自动暂停。

| 256 | 福州三中 |

数字顺序用于游戏设计，不代表学校排名。

## 求解器

求解器使用 Expectimax 搜索，考虑每次随机生成 2（90%）或 4（10%）的情况，并综合空格、可合并方块和棋盘的数值排列。计算在 Web Worker 中进行；无 Worker 的浏览器使用较短搜索时间的兼容模式。它通过正常移动进行游戏，遵循同样的随机生成规则，无法保证每局必胜。

## 运行与部署

直接用浏览器打开 `index.html` 即可离线游玩，也可以部署到支持静态文件的网站托管服务。GitHub Pages 使用 `main` 分支根目录作为发布来源。

## 素材

学校标识归相应学校所有。本项目是非官方趣味作品，校徽仅用于辨识学校，不表示学校认可或参与本项目。游戏内“素材来源”提供逐一对应的链接。八中使用其官网页眉的紫红色圆形校徽，三中校徽取自官网历史存档。
